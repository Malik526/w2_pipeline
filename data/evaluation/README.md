# Evaluation Data

This directory is reserved for future offline benchmark datasets and ground
truth.

Phase 0 does not add benchmark documents, synthetic W-2s, ground truth files,
evaluation runners, or scoring code.

Future evaluation data must be safe to commit. Preferred sources are synthetic
W-2s, fake names, fake SSNs, fake EINs, fake addresses, public blank IRS forms,
or appropriately licensed open datasets without sensitive taxpayer information.

Keep authoritative blank IRS reference forms under `docs/references/`, not in
this directory.

Future benchmark results should remain segmentable by tax year.
